# ~/code — Huey's repo workspace

This folder is the root for all of Huey's repos (GitHub: **hueyb-art**). New repos get cloned here. This file is local-only (not in any repo); a versioned copy lives at `the-music-constellation/docs/code-root-CLAUDE.md` — update both together.

## Repos

- **the-music-constellation/** — the active project. One web app, **four** genre constellations (jazz, hip hop, reggae, **classical**) with a genre switcher. Jazz, hip hop and reggae are hand-authored; classical is **generated by an importer** from `~/Desktop/Composers and Musical Movements/` (712 composers, patrons and theorists; a **local-only git repo**, no remote), the same pattern as the art constellation. Genres are **lazy-loaded**, so a visitor downloads only the one they open. All four offer globe, chord and timeline views. Every artist CV across all four genres is written from a per-artist evidence pack and adversarially fact-checked; the **About the data** tab in Rooms is the public provenance note for that. Full agent context in its `CLAUDE.md`; curation format in `docs/DATA-FORMAT.md`; deferred work in `docs/ROADMAP.md`. Live: https://hueyb-art.github.io/the-music-constellation/
- **the-art-constellation/** — the same engine adapted to **20th-century visual art** (883 artists, 90 movements, 7 eras), as its own standalone project rather than a fourth "genre". Adds a **Timeline view** (movements as dated clusters you pan through time, clusters bloom open on hover) and an **enrichment layer** — biographies, lifespans, portraits and freely-licensed artwork images, harvested from Wikidata/Wikipedia. Source data is authored as markdown in `~/Desktop/20th Century Art Movements/` and imported; that folder is a **local-only git repo** (no remote — this repo is public and the markdown is the curation). See its `CLAUDE.md`. Live: https://hueyb-art.github.io/the-art-constellation/
- **the-science-constellation/** — a third constellation, standalone, with the model **inverted**: the stars are **ideas, not people** (everyone knows what gravity is and cannot name Newton), and the scientist is the reveal when a star opens. 454 concepts from c. 600 BC to the present across 8 eras, 821 idea-to-idea connections of eight kinds, each concept carrying a plain statement of what it claims and, where one exists, its equation typeset with KaTeX. **Source markdown lives in the repo at `source/`** — moved off the Desktop 2026-09-12, because the thing everything is generated from had no history. **Private repo, all rights reserved** — created 2026-09-10, deliberately not on the open licences the earlier repos picked up as scaffolding. Its timeline axis is **piecewise**, not linear, because 2,600 years of ideas are wildly unevenly spread. See its `CLAUDE.md`. Not deployed — runs locally on port 8752.
- **the-surveillance-map/** — a different animal from the constellations: not a curated corpus but a **pipeline with a website on the end of it**. A live world map of surveillance technology aimed at people — deployments, contracts, legislation, abuse, pushback — each dot linked to the reporting. Feeds and public APIs only (18 outlets, 18 Google News queries, GDELT), never HTML scraping; a keyword prefilter discards ~75% for free, then **Claude Haiku** judges what survives and returns a *place name*, never coordinates, so a wrong answer fails against the gazetteer instead of landing a dot in the sea. Canvas, vanilla ES modules, no build step. **Private repo, all rights reserved** — created 2026-09-13, same footing as the science constellation. Needs `ANTHROPIC_API_KEY`; refreshed by a GitHub Action four times a day. Not deployed (private repo, so Pages needs a paid plan) — runs locally on port 8763. See its `CLAUDE.md`.
- **the-medical-map/** — the second project of the surveillance map's shape, and proof the pattern generalises: a world map of **advances in medical treatment and research**. The engine was copied, not shared (two instances is too few to know the common core). Two things make it its own thing: a dot is the **lead research institution**, matched against ROR's 133,640 registered organisations — Huey's explicit choice on 2026-09-13, and the right one because it is *checkable*; and the taxonomy is an **ordered ladder** (lab → animal → early trial → late trial → approved → in use) rather than a set of categories, because a cure in mice and a phase 3 result are written up identically and are not the same news. Registries are primary (Europe PMC, ClinicalTrials.gov results, medRxiv) and news secondary — the opposite of its sibling. Clicking an advance opens a **detail page** with a plain-English claim, the key caveat, every merged source link, and related work. **Private repo, all rights reserved.** Needs `ANTHROPIC_API_KEY`. Not deployed — runs locally on port 8764. See its `CLAUDE.md`.
- **jazz-constellation/**, **hiphop-constellation/**, **reggae-constellation/** — legacy single-file apps, superseded by the above. **Do not modify** until the post-validation handover step in the-music-constellation/docs/ROADMAP.md (README notes + redirects, only after Huey confirms the new site works).

## Standing workflow rules (from Huey, 2026-06-12)

1. **Ask first.** Reach alignment via clarifying questions (one at a time, with a recommended answer) before structural changes. Explore the code instead of asking when the code can answer.
2. **Validate, then commit AND push.** Repos must stay current on GitHub, but only push when validation passes (`node scripts/validate.mjs` in the-music-constellation) and the app is stable.
3. **Capture learnings** in the repo's `docs/LEARNINGS.md`; keep READMEs and CLAUDE.md files current as part of the work, not as an afterthought.
4. Commit messages should describe the change (the legacy repos' history is all "Add files via upload" — don't add to it).
